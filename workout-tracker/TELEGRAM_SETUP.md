## Шаг 1: Размещение приложения на GitHub Pages

### Вариант A: Автоматический деплой через GitHub Actions (рекомендуется)

1. Убедитесь, что все файлы загружены в репозиторий `https://github.com/kristina03030609/TrainMy.git`
2. Перейдите в настройки репозитория: Settings → Pages
3. В разделе "Source" выберите "GitHub Actions"
4. После первого push в ветку `main` приложение автоматически задеплоится
5. Ваше приложение будет доступно по адресу: `https://kristina03030609.github.io/TrainMy/workout-tracker/`

### Вариант B: Ручная настройка GitHub Pages

1. Перейдите в настройки репозитория: Settings → Pages
2. В разделе "Source" выберите ветку `main` и папку `/ (root)`
3. Нажмите "Save"
4. Подождите несколько минут, пока GitHub обработает запрос
5. Ваше приложение будет доступно по адресу: `https://kristina03030609.github.io/TrainMy/workout-tracker/`

**Важно:** Убедитесь, что файлы находятся в папке `workout-tracker/` в репозитории, иначе URL будет другим.

## Шаг 2: Настройка Mini App в BotFather

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newapp`
3. Выберите вашего бота из списка (или создайте нового, если еще не создан)
4. Введите название приложения: **Трекер Тренировок**
5. Введите описание приложения (например: "Приложение для отслеживания тренировок")
6. Загрузите иконку приложения (512x512px, PNG) - опционально
7. Введите URL вашего приложения: `https://kristina03030609.github.io/TrainMy/workout-tracker/`
   - **Важно:** Убедитесь, что GitHub Pages уже настроен и URL доступен

## Шаг 3: Настройка кнопки меню бота

Чтобы пользователи могли легко открыть приложение:

1. Отправьте `/mybots` боту BotFather
2. Выберите вашего бота из списка
3. Выберите "Bot Settings" → "Menu Button"
4. Выберите ваше Mini App из списка

Теперь кнопка для открытия приложения будет отображаться в меню бота.

## Шаг 4: Запуск бота (опционально)

Если вы хотите, чтобы бот автоматически отвечал на команды:

1. Установите Node.js (если еще не установлен)
2. В папке проекта выполните:
   ```bash
   npm install
   ```
3. Запустите бота:
   ```bash
   npm start
   ```

Бот будет отвечать на команду `/start` и предлагать открыть приложение.

**Примечание:** Для работы бота нужен постоянно работающий сервер. Вы можете использовать:
- Бесплатные хостинги: Heroku, Railway, Render
- VPS сервер
- Или просто использовать кнопку меню в боте (без запуска бота)

## Шаг 5: Тестирование

1. Откройте вашего бота в Telegram
2. Нажмите на кнопку меню (три линии) или кнопку "Menu" внизу экрана
3. Выберите ваше Mini App
4. Приложение должно открыться внутри Telegram

Или отправьте боту команду `/start` - бот отправит кнопку для открытия приложения.

## Важные замечания

1. **HTTPS обязателен** - Telegram требует безопасное соединение
2. **Домен должен быть валидным** - не используйте localhost для продакшена
3. **Файлы должны быть доступны** - убедитесь, что все файлы (HTML, CSS, JS) доступны по указанному URL
4. **Тестирование** - используйте Telegram Desktop или мобильное приложение для тестирования

## Отладка

Если приложение не открывается:

1. Проверьте, что URL доступен и возвращает HTML
2. Проверьте консоль браузера (в Telegram Desktop: View → Developer Tools)
3. Убедитесь, что все файлы загружаются без ошибок
4. Проверьте, что используется HTTPS

## Использование данных пользователя Telegram

Приложение уже настроено для автоматической работы с данными пользователя Telegram:

### Автоматическое создание пользователя

При первом открытии приложения в Telegram:
- Автоматически создается пользователь на основе данных из Telegram (имя и фамилия)
- Пользователь автоматически выбирается и готов к использованию
- Данные сохраняются локально в браузере

### Доступные данные Telegram

В коде уже реализована функция `initTelegramUser()`, которая:
- Получает данные пользователя из Telegram
- Создает пользователя с уникальным ID на основе Telegram ID
- Сохраняет имя, фамилию и username (если есть)

### Дополнительные возможности Telegram Web App API

Вы можете использовать следующие методы Telegram Web App API:

```javascript
// Закрыть приложение
tg.close();

// Показать всплывающее окно
tg.showAlert('Сообщение');

// Показать подтверждение
tg.showConfirm('Вы уверены?', (confirmed) => {
    if (confirmed) {
        // действие
    }
});

// Показать основную кнопку
tg.MainButton.setText('Сохранить');
tg.MainButton.show();
tg.MainButton.onClick(() => {
    // действие при нажатии
});

// Отправить данные боту
tg.sendData(JSON.stringify({ action: 'save', data: {...} }));
```
