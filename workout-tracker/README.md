# 💪 Трекер Тренировок

Веб-приложение для отслеживания ваших тренировок с календарем и историей занятий.  
**Теперь доступно как Telegram Mini App!** 🤖

## Возможности

✅ **Создание программ тренировок** - сохраняйте свои программы с упражнениями  
✅ **Календарь тренировок** - визуально отслеживайте частоту и типы тренировок  
✅ **Запись тренировок** - фиксируйте подходы, повторения и вес  
✅ **История тренировок** - при записи новой тренировки отображаются результаты предыдущего занятия  
✅ **Telegram Mini App** - работает прямо в Telegram с автоматическим созданием пользователя

## Как использовать

1. Откройте файл `index.html` в браузере
2. **Создайте программу тренировок:**
   - Перейдите на вкладку "Программы"
   - Нажмите "+ Создать программу"
   - Введите название программы
   - Добавьте упражнения
   - Сохраните программу

3. **Запишите тренировку:**
   - Перейдите на вкладку "Записать тренировку"
   - Выберите дату тренировки
   - Выберите программу
   - Заполните данные о подходах, повторениях и весе
   - При заполнении вы увидите информацию о предыдущей тренировке

4. **Просмотр календаря:**
   - Перейдите на вкладку "Календарь"
   - Дни с тренировками выделены фиолетовым цветом
   - Кликните на день, чтобы увидеть детали тренировок

## Технические детали

- Данные сохраняются в локальном хранилище браузера (localStorage)
- Не требует сервера - работает полностью в браузере
- Адаптивный дизайн для мобильных устройств
