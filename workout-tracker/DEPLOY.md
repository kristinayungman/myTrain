# 🚀 Инструкция по деплою на GitHub Pages

## Шаг 1: Подготовка репозитория

1. Убедитесь, что все файлы проекта загружены в репозиторий:
   - `index.html`
   - `app.js`
   - `styles.css`
   - Остальные файлы проекта

2. Структура должна быть:
   ```
   TrainMy/
   └── workout-tracker/
       ├── index.html
       ├── app.js
       ├── styles.css
       └── ...
   ```

## Шаг 2: Настройка GitHub Pages

### Способ 1: Через GitHub Actions (автоматический деплой)

1. Перейдите в ваш репозиторий: https://github.com/kristina03030609/TrainMy
2. Перейдите в **Settings** → **Pages**
3. В разделе **Source** выберите **GitHub Actions**
4. Файл `.github/workflows/deploy.yml` уже создан и настроен
5. Сделайте commit и push в ветку `main`
6. GitHub автоматически задеплоит приложение
7. Через несколько минут приложение будет доступно по адресу:
   ```
   https://kristina03030609.github.io/TrainMy/workout-tracker/
   ```

### Способ 2: Через настройки репозитория (ручной)

1. Перейдите в ваш репозиторий: https://github.com/kristina03030609/TrainMy
2. Перейдите в **Settings** → **Pages**
3. В разделе **Source** выберите:
   - Branch: `main`
   - Folder: `/ (root)` или `/workout-tracker` (в зависимости от структуры)
4. Нажмите **Save**
5. Подождите несколько минут
6. Приложение будет доступно по адресу:
   ```
   https://kristina03030609.github.io/TrainMy/workout-tracker/
   ```

## Шаг 3: Проверка деплоя

1. Откройте в браузере: `https://kristina03030609.github.io/TrainMy/workout-tracker/`
2. Убедитесь, что приложение загружается корректно
3. Проверьте, что все файлы доступны (откройте консоль разработчика F12)

## Шаг 4: Обновление URL в BotFather

После успешного деплоя:

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/myapps`
3. Выберите ваше приложение
4. Обновите URL на: `https://kristina03030609.github.io/TrainMy/workout-tracker/`

## Важные замечания

- ⚠️ GitHub Pages может занять до 10 минут для первого деплоя
- ⚠️ Убедитесь, что репозиторий публичный (или у вас есть GitHub Pro)
- ⚠️ URL чувствителен к регистру и должен точно совпадать
- ⚠️ После каждого изменения в коде нужно делать commit и push

## Отладка

Если приложение не открывается:

1. Проверьте, что URL правильный и доступен в браузере
2. Проверьте консоль браузера на ошибки (F12)
3. Убедитесь, что все файлы загружены в репозиторий
4. Проверьте настройки GitHub Pages в Settings → Pages
